项目标题：基于YOLOv8的红绿灯识别系统

一、项目简介
本项目是一个集模型训练、图形化界面推理于一体的红绿灯识别系统。基于YOLOv8目标检测算法，支持多格式图片输入、实时检测结果可视化、置信度阈值调节，可精准识别红/绿/黄三种灯色。

二、核心功能
1.支持模型训练：基于自定义红绿灯数据集，自动完成模型训练与最优权重保存
2.图形化推理界面：通过PyQt5实现可视化操作，无需命令行基础
3.多格式图片兼容：支持jpg、png、jpeg、bmp格式图片检测
4.结果自动保存：检测后的带框图片、分类统计总表自动归档，便于追溯
5.阈值灵活调节：支持0.1\~0.9置信度阈值调节，适配不同精度需求

三、依赖安装

1. 下载项目压缩包，解压后进入项目根目录
2. 打开终端，执行以下命令一键安装所有依赖（依赖清单已在requirements.txt中记录）：
pip install -r requirements.txt

五、操作步骤
1.输入数据准备
（1） 数据存放
直接选择项目根目录中的「测试图」文件夹内的红绿灯图片
（2） 支持的数据格式
图片格式：支持 jpg、png、jpeg、bmp，无需格式转换，可直接导入检测。
2.程序运行步骤
打开终端，进入项目根目录，输入以下命令，启动图形化推理界面：python predict\_pic.py
3.结果输出路径
（1）带检测框的图片：保存至runs/predict/pic\_result/result/（与输入图片同名）
（2）统计总表：runs/predict/pic\_result/result/灯色分类统计总表.txt（记录每张图的检测结果）
示例参考：项目根目录内的「结果图」文件夹中存放了已完成检测的示例结果，可直接查看参考检测效果
项目根目录内的「灯光分类统计总表」存放了已完成检测的统计结果，可直接查看参考统计结果

六、界面说明
GUI 可视化操作流程：
1.点击「选择图片」：从本地任意路径或项目「测试图」文件夹中，选择需要检测的红绿灯图片
2.调节「置信度阈值」：默认 0.25，数值越高检测越严格，可根据图片清晰度微调
3.点击「开始检测」：左侧显示原始图片，右侧显示带检测框的结果图（红 / 绿 / 黄框对应不同灯色，框旁标注置信度）
4.点击「清空内容」：重置界面，可重新选择图片进行新一轮检测
